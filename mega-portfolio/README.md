# Mega Chaudhary · Portfolio

React + three.js portfolio with light and dark themes.

- Hero: your real project screens floating in 3D, a pixel-scan portrait and Figma-style live cursors
- About: an editor window; location.md draws Nepal as a pixel map made from your photo
- Work: a 3D carousel + index; each project opens a full case-study page in that project's own colours,
  with real screenshots (FacultyHub, Memora, Raksha, Higanbana, Particle Heart, Will You Be Mine)
- Skills: a realistic 3D macropad (tapered keycaps, aluminium case, OLED, knob, click sound)
- Contact: a dotted 3D globe with Nepal highlighted

Built with React, Vite, three.js / React Three Fiber, framer-motion and Lenis smooth scrolling.

## Run it on your computer

1. Install Node.js 18+ from nodejs.org.
2. Open this folder in VS Code, then in the terminal:

```bash
npm install
npm run dev
```

3. Open the address it prints (usually http://localhost:5173).

## Change your content

Everything you'd want to edit is in **`src/data.js`**: your name, intro, email, stats, the About files,
all projects, services, keyboard keys and the timeline.

- **Add screenshots to a project:** put the image in `src/assets/`, import it at the top of `data.js`,
  and use it in that project's `media` (see the Higanbana project for an example with a video and gallery).
- **Photos:** only two are used: `src/assets/mega-golden.webp` (hero + About) and `mega-bw.webp` (About, Nepal map, Contact).
- **Memora QR:** `src/memora/` is your own HeartQR renderer from the Memora project, used live on the site.
- **Map + globe data:** `src/geo/` is generated by `node scripts/build-geo.mjs` (only needed to change detail).
- **Project colours:** each project in `data.js` has a `theme` (bg, ink, accent) used on its card and page.

## Put it online free (GitHub Pages)

```bash
npm run build
```

This makes a `dist/` folder. Upload the **contents** of `dist/` to a GitHub repo
(for example `mega-chaudhary/portfolio`), then on GitHub: *Settings → Pages → Deploy from branch → main / root*.
Your site will be at `https://mega-chaudhary.github.io/portfolio/`.

Netlify or Vercel also work: drag the `dist/` folder onto netlify.com/drop.

`npm run build:single` makes one self-contained `dist-single/index.html` (everything inlined) if you ever need a single file.
